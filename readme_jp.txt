RegexPad
========
Release: 1.0.0 (Stable)
リリース：1.0.0 安定版
リリース日：2026年10月25日

Windows 11向けのポータブルテキストエディターです。
正規表現による検索・置換、HTML・CSS・WordPress原稿の編集補助と、
ローカルWordPressプレビューを利用できます。

起動方法
1. 配布ZIPを、書き込み可能なフォルダーへすべて解凍します。
2. regex-pad.exe、module_cleaner.exe、_internalを同じ配置で保持します。
3. regex-pad.exeを起動します。「言語」で日本語・英語を選べます。
4. Ctrl+Oで原稿を開き、Ctrl+Sで保存します。

完全同梱版では、Python・WordPress・PHP・MySQL・Nodeの別途導入は不要です。
通常の編集はオフラインで使えます。プレビュー環境を省いた軽量版では、
利用者が初めてプレビューを実行したときに不足資材を取得します。
その準備や、記事内の外部画像などの参照にはインターネット接続が必要です。

主な操作
- Ctrl+F：検索・置換、正規表現、除外条件、置換プレビュー
- F7：現在のタブのHTML・CSS・WordPress文法チェック
- Ctrl+Shift+T：タグ・スニペット挿入
- 本文を右クリック：CSS・文字色の挿入、Markdown表・リスト変換など
- Ctrl+Alt+P：中立テーマによる簡易WordPressプレビューとHTML書き出し
- Ctrl+Alt+Shift+P：Twenty Twenty-Fiveによる本格プレビュー
- Ctrl+,：表示・バックアップなどのオプション
- F1：アプリ内の使い方

文法チェックとプレビューは、原稿を自動修復しません。
置換・正規表現書き換え・挿入・変換は、利用者が明示的に実行する編集操作です。
文法チェックのJSON対象はWordPressブロックコメント内の属性です。
実際のWordPressへ貼り付ける際は、元原稿を残して確認してください。

プレビュー
編集後は、使いたいモードのプレビューを再実行します。
実行のたびに未保存の最新内容を送ります。
ブラウザーの再読み込みだけでは、エディターの変更を送信しません。

簡易版は書き出し後に、そのプレビュー用WordPressを終了します。
本格版は「WordPressを終了」または所有するエディターウィンドウの終了まで保持します。
簡易版を書き出しても、別に起動中の本格版は終了しません。
約10秒後に準備済みの簡易環境を先行起動しますが、使用可能になる時間の保証ではありません。
自動先行起動では不足資材を取得しません。状態はステータスバー右のWP表示で確認できます。

同梱する説明書
このEXEと同じ階層に、次の文書を置いています。
- readme.txt：英語の簡易説明
- LICENSE.txt：プロジェクトのライセンス文書
- README.md / README_jp.md：英語・日本語の概要と導入案内
- docs/HOW_TO_USE.md：英語の詳しい使い方
- docs_jp/HOW_TO_USE_jp.md：日本語の詳しい使い方
- docs/images/：ガイドに掲載する画像
- SCRIPT_STEP.md：開発・検証の記録

Markdown文書はテキストでも読めます。
表・リンク・画像を整えて表示する場合は、Markdown対応のビューアーを使います。
文書と画像の相対パスを保つため、配布フォルダー全体を保持してください。

設定と復元
設定：EXEの横のconfig.json
編集可能な配色：EXEの横のcolor_presets.json
保存前の世代バックアップ（既定）：_internal/backup/
未保存内容の復元データ：_internal/autosave/

「ファイル > バックアップから復元」で読み込み、確認してから保存します。
自動復元用のコピーは、原稿ファイルそのものを更新しません。
変更済みタブを閉じる前に、明示的に保存してください。

削除・整理
RegexPadとプレビューを終了し、このフォルダーで先に候補を確認します。
    .\module_cleaner.exe --dry-run
その後、必要な場合に実行します。
    .\module_cleaner.exe --clean

削除にはDELETEの入力が必要です。
WordPress資材とTemp/WordPressPreview/内の書き出しページも対象になるため、
必要な原稿・書き出し・バックアップは事前に別の場所へ保存してください。

EXEが実際の保存先一覧を次に作成します。
- _internal/DELET_ITEMS_LIST.md
- install_records/DELET_ITEMS_LIST.md
フォルダー削除前に一覧を別の場所へ保存すると、手動確認にも利用できます。
共有される可能性のある参照先は末尾の警告欄にまとめ、自動削除の対象に追加しません。
アプリから作成する永続的なシステム環境変数・レジストリーキーはありません。
